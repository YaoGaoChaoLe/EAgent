# 易Agent 
0 tokens、0门槛 、轻量级 | 基于 DeepSeek 网页版制作的 Agent —— 让 网页版 AI "操控"你的电脑。
```
除了 deepseek 网页，现已支持 豆包、元宝、智谱清言 的网页版！
```

## 1. 环境要求
- 仅支持 Win 10~11 操作系统
- 必装 Edge 浏览器 （电脑自带，除非你给它卸了）

## 2. 适用场景

### 用网页版 AI 写项目，一般流程如下：
    扔文件、描述需求 → Ai给你代码 → 我复制粘贴+自己修改文件 → 运行 → 报错了再扔给Ai

    ...非常麻烦！！

### 网页编程，痛点是啥？
    不能自动读我的电脑文件、不能自动修改我的电脑文件、不能自动运行、不知道代码运行结果...

### 本项目给 网页-电脑 搭了一座"桥"，解决以上痛点，实现：
    让网页版Ai —— 修改你电脑文件、看你电脑屏幕、控制你键盘和鼠标、
    编辑 Excel/Word、甚至当QQ微信机器人（骚操作，不建议）

    ...只要你敢想，它还能更多！

## 3. 与其它项目相比，有啥区别？
| 项目类型 | 合规性 | 特点 | 原理 |
| --- | --- | --- | --- |
| DeepSeek Harness 等 | 正规 | 功能强大；但要 API、花钱买 token。 | 调用官方 API |
| 网页反代 等 | 不正规 | 功能强大；要 API、封号概率大 | 调用非官方接口/逆向网页 |
| **EAgent (本项目)** | **不正规** | **功能轻量；但不花钱买 token、无需 API、封号概率小（但不是 0%）** | **自动化脚本操控浏览器，模拟人类行为** |


## 4. 快速使用
- 下载文件：[点我下载](https://github.com/YaoGaoChaoLe/EAgent/releases)
- 右键 `EAgent.exe`，以管理员身份运行。`而不是直接双击打开`
- 进入程序，点击 `选择工作目录` 按钮，选择一个目录。
- 然后会自动打开 Edge 浏览器。请自行登录后，才能进行下一步操作。
- 在 EAgent 中点击 `开始新对话` 。等待 Ai 分析提示词...
- 到你回复它了 —— 用 EAgent 发消息，而**不是用网页版发消息**。 `网页版的唯一作用就是给你看的，而不是发消息的。`
- 如果看不懂以上文字：[演示视频](https://www.bilibili.com/video/BV1dZJk6wEHG/)
